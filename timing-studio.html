TimingStudio

static timing analysis engine — Liberty in, gate-level Verilog in, critical paths out. Runs entirely in your browser.
v0.1 · prototype

What this tool does

This is a real static timing analysis (STA) engine — the same class of tool as Synopsys PrimeTime (the industry sign-off standard, ~$300K–1M/seat/yr) and the open-source OpenSTA. It:
  1. Parses your Liberty (.lib) library — cells, pin caps, and NLDM delay/transition lookup tables with bilinear interpolation
  2. Parses your structural gate-level Verilog netlist (flatten hierarchical modules; for RTL run Yosys first)
  3. Reads SDC constraints — create_clock, set_input_delay, set_output_delay, set_load, set_input_transition
  4. Propagates rise/fall arrival times and slews through every cell (per arc, honouring unateness) and net (fanout-based interconnect model)
  5. Checks setup and hold at sequential pins and outputs, computes slack / WNS / TNS, and traces critical paths stage-by-stage

Why it matters for India

Timing sign-off is the single most-used analysis step in digital chip design — run daily by every design team on earth, and dominated by one foreign tool. A free, auditable, browser-based STA engine gives students, startups and MSMEs the ability to close timing on mature nodes without a PrimeTime licence — and a foundation for a serious Indian alternative (add SPEF interconnect, propagated clocks, and MCMM, and it approaches production use).

Quick reference

create_clock -name clk -period 2.0 [get_ports clk]
set_input_delay 0.2 [get_ports {a b cin}]
set_output_delay 0.1 [get_ports {s*}]  — patterns not yet supported, list ports
Net delay model: delay = (fanouts − 1) × net-delay knob (top left). Input slews default to the knob value. Clock is ideal (zero skew). Units come from the Liberty file (ns / pF here).

Engine notes

Modified graph-traversal STA: topological propagation with Kahn's algorithm, unateness-aware edge selection, per-edge arrival/slew state, NLDM bilinear lookup with clamping, ideal clocks, loop detection. Verified against hand-computed paths (pipeline: clk2q + 3 gates = exact; 4-bit ripple-carry adder carry-chain = exact).
